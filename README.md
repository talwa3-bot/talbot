# כלי ריבית רעיונית ובודק משיכות בעלים

כלי אופליין לרואי חשבון. קובץ HTML אחד, בלי שרת ובלי אינטרנט. הנתונים לא יוצאים מהמחשב.

## איך משתמשים (4 צעדים)

1. פותחים את `app/dist/shareholder-interest-tool.html` בדפדפן (לחיצה כפולה על הקובץ).
2. ממלאים שם חברה ושם מכין, ומעלים כרטסת אחת או יותר (`xlsx`, `xls`, `csv`).
3. בוחרים שנת מס ובודקים את השיעורים. 2025 ו-2026 מוזנים מראש. שנים אחרות מזינים ידנית.
4. מורידים את נייר העבודה מהלשונית הרצויה.

## מה הכלי מפיק

**לשונית 1: ריבית רעיונית 3(ט) / 3(י) / 3(ט1)**
- נייר עבודה באקסל, מימין לשמאל, מותאם לשיטת רם ניהול פלוס.
- כולל שורת יתרת פתיחה נפרדת, חישוב חודשי לפי ימים בפועל, פקודת יומן ובקרות.
- הנוסחאות באקסל חיות: משנים שיעור או ימים והחישוב מתעדכן.

**לשונית 2: בודק משיכות בעלים וניתוח כרטסת**
- סיווג כל תנועה (שכר, דיבידנד, הלוואה, משיכה פרטית ועוד), ניתן לתיקון ידני.
- דגלים: משיכה גדולה, סכום עגול, תנועה כפולה, החזר ומשיכה חוזרת, החזר סמוך לסוף שנה.
- חשיפות (הלוואה, דיבידנד מוסווה, שכר), חלופות סיווג, מסמכים מומלצים ופעולות תיקון.
- נייר העבודה נקרא "ניתוח כרטסת בעל מניות".

## כמה כרטסות

- כרטסות עם אותו שם בשדה "קבץ לפי" מתאחדות לנייר עבודה אחד של אותו בעל מניות.
- כרטסות עם שמות שונים מקבלות כל אחת נייר עבודה נפרד.

## בנייה ובדיקות

```
npm run build   # בונה את app/dist/shareholder-interest-tool.html
npm test        # בדיקות חישוב, קריאת קבצים, סיווג וייצוא
```

## מה חשוב לדעת

- **שיעורי 2026** (3ט 6.53%, 3י 4.9%) נלקחו מפרסומים ציבוריים ולא אומתו מול החוזר המקורי. יש לאמת.
- **סעיף 3(ט1)**: אין שיעור מובנה. מזינים ידנית.
- הסיווג האוטומטי מבוסס על מילות מפתח בתיאור התנועה. החשיפות הן אומדנים להמחשה. הקביעה המקצועית נשארת אצל הסוקר.
- קבצי האקסל יורדים עם שם באנגלית כדי להבטיח סיומת תקינה בכל דפדפן. אפשר לשנות שם אחרי ההורדה.
- קובץ לדוגמה: `app/examples/sample-ledger.xlsx`.
