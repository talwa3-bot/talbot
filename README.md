# טורניר הברידג' העולמי

משחק ברידג' תחרותי בעברית, מותאם לגיל השלישי. רץ בדפדפן, באייפון, באייפד ובמחשב, בלי התקנה.

## מה יש במשחק
- **טורניר דופליקייט** אמיתי: חלוקות קבועות, פגיעות ומחלק לפי הלוח הרשמי, ניקוד מלא (כפל, כפל חוזר, סלאמים).
- **זוגות מכל העולם** עם דגלים ודירוג, החלפת שולחן כל שתי חלוקות, פתק תוצאות אחרי כל חלוקה וטבלת דירוג חיה.
- **בוטים חזקים:** משחק הקלפים מבוסס על פותר "דאבל דאמי" ([bridge-solver](https://github.com/bridge-craftwork/bridge-solver), רישיון MIT) עם דגימת מונטה קרלו. ההכרזות בשיטה טבעית בסגנון אמריקאי (מייג'ור 5, 1NT 15-17, סטיימן, בלאקווד, כפל הוצאה וכפל שלילי).
- **נוח לגיל השלישי:** קלפים וטקסט גדולים, לחיצה ואישור (בלי טעויות מקריות), בלי שעון, קצב רגוע, עצה מהשותפה, שמירה אוטומטית.

## הפעלה מקומית
```sh
npm install        # רק לבדיקות
npm run serve      # ואז לפתוח http://localhost:8080
```

## בדיקות
```sh
npm run check      # בדיקת טיפוסים (TypeScript על JavaScript) + בדיקות יחידה
npm run sim        # סימולציית הכרזות: כמה חוזים מצליחים מול הפותר
node tests/sim-play.mjs 8   # משחק מלא של בוטים מול התוצאה התאורטית
```

## פרסום לאינטרנט (GitHub Pages)
1. בהגדרות הריפו: Settings → Pages → Source: **GitHub Actions**.
2. כל מיזוג ל-`main` מפרסם אוטומטית.
3. באייפון: לפתוח את הקישור בספארי → שיתוף → **הוסף למסך הבית**. המשחק נפתח כמו אפליקציה ועובד גם בלי אינטרנט.

## מבנה
- `src/engine` חוקי המשחק: קלפים, הכרזות, משחק, ניקוד.
- `src/ai` הבוטים: הכרזות (`bid-ai.js`), משחק (`play-ai.js`), עובד רקע עם הפותר.
- `src/game` חלוקה וטורניר.
- `src/ui` הממשק.
- `docs/DESIGN.md` החלטות העיצוב והמומחים.
