# קבצי דמה ללמידה ולבדיקה

כל הקבצים כאן סינתטיים. הם מדמים ייצוא ממערכת הנהלת חשבונות של חברה בדויה, בדולרים.

## ארבעה מושגים לפני שמתחילים

1. **ביצוע:** מה שבאמת קרה. הכסף שנכנס ויצא בפועל, לפי ספרי החשבונות.
2. **תקציב:** מה שתכננו מראש. בדרך כלל נקבע לפני תחילת השנה.
3. **סטייה:** ביצוע פחות תקציב. בהוצאות, סטייה חיובית פירושה שהוצאנו יותר מהמתוכנן, כלומר חריגה.
4. **סכום בקרה:** הסכום הכולל שמופיע בדוח המקורי. המערכת מחברת את כל השורות בקובץ ומשווה לסכום הזה. אם הם שונים, סימן שחסרות שורות או שיש שורות מיותרות.

## מסלול תרגול באתר ההדגמה

1. היכנסי כ**מנהלת נתונים** ועברי ל**קליטת נתונים**.
2. העלי את קובץ 03 עם סכום בקרה `20000.00`, וקראי את טבלת הבעיות.
3. העלי את קובץ 01 עם סכום בקרה `416601.25`, ולחצי **פרסום**.
4. בחרי סוג קובץ **תקציב**, העלי את קובץ 02 עם `792000.00`, ולחצי **פרסום**.
5. צאי והיכנסי כ**סמנכ״ל כספים**. שאלי: "מה החריגה בהוצאות התפעול ברבעון השני?"

**שימי לב לפרט אחד:** במאי יש הוצאה של 1,250.50 בחשבון 6200 (הוצאות אחרות), שלא תוקצבה בכלל. כשהתקציב הוא אפס, אי אפשר לחשב אחוז, ולכן המערכת מציגה "לא רלוונטי" ומראה רק את הסכום.

## למה קובץ הביצוע כולל את כל החודשים מתחילת השנה

במערכת הזו כל פרסום של ביצוע מחליף את הגרסה הקודמת בשלמותה, והגרסה הקודמת נשמרת בהיסטוריה. לכן מעלים ייצוא מתחילת השנה ועד היום, ולא רק את החודש האחרון. אם הייתם מעלים רק את יוני, השאלות על ינואר היו נענות ב"אין נתונים".
