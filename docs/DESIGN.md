# החלטות עיצוב: פאנל המומחים

## 1. מומחה ברידג'
| החלטה | למה |
|---|---|
| דופליקייט עם אחוזי מאץ'-פוינט | זו חוויית הטורניר האמיתית שאלופה מכירה; כל חלוקה מושווית לשולחנות אחרים. |
| לוח פגיעות ומחלק רשמי (16 חלוקות) | אמינות מלאה לחוקים. |
| ניקוד מלא כולל כפל, כפל חוזר, עלבון, סלאמים | "כל החוקים". נבדק בבדיקות יחידה. |
| שיטה טבעית אמריקאית | הנפוצה ביותר. **לבדוק עם סבתא באיזו שיטה היא משחקת** (למשל טרנספרים של ג'קובי, 2 על 1). |
| משחק קלפים: מונטה קרלו + פותר דאבל-דאמי | השיטה של הבוטים החזקים. בבדיקה: בממוצע פחות מחצי לקיחה מתחת למשחק מושלם. |
| הבוטים לא מרמים | בוחרים קלף רק לפי מה שמותר לראות: היד, הדומם, הקלפים ששוחקו והמכרז. |
| תוצאות השדה = הכרזת בוטים עם שונות קטנה + תוצאה מושלמת עם רעש אנושי | נותן פתק תוצאות מגוון ואמין. |

## 2. מומחה גיל שלישי (ארגונומיה)
- טקסט בסיס 20px כפול 1.15, אפשר להגדיל ל-1.3. קלפים עם ספרה ענקית.
- כל כפתור לפחות 52 עד 56 פיקסלים, מרווחים גדולים (רעד בידיים).
- **לחיצה ואישור**: לחיצה ראשונה מרימה קלף או בוחרת הכרזה, לחיצה שנייה מאשרת. אפשר לכבות.
- קלפים לא חוקיים מוחלשים ולא מוסתרים, כדי שהיד תיראה תמיד שלמה.
- ניגודיות גבוהה, אפשרות לחפיסה של 4 צבעים, וסימן הסדרה תמיד מופיע (לא רק צבע).
- אין שעון. הקצב "רגוע" כברירת מחדל. הלקיחה נשארת על השולחן כ-2 שניות.
- המסך לא נכבה באמצע משחק (Wake Lock).
- שמירה אוטומטית אחרי כל מהלך.

## 3. מומחה פסיכולוגיה
- פנייה אישית בשם ובלשון נקבה.
- תחושת תחרות אמיתית: זוגות מכל העולם, דגלים, דירוג, "שחקנים מחוברים", החלפת שולחן, פודיום.
- משוב מכבד: גם בתוצאה חלשה, ניסוח עידודי ("חלוקה קשה. ממשיכים!") לצד הנתון האמיתי.
- תחושת שליטה: עצה מהשותפה, הלקיחה הקודמת, "כל השאר שלי".
- אמת: בעמוד העזרה כתוב שהשחקנים מופעלים על ידי מחשב. כדאי לא להוסיף "צ'אט" מזויף או לחץ חברתי.

## 4. מומחה גרפיקה
- לבד ירוק של שולחן טורניר, תגיות מושבים עם דגל, מסגרת אדומה = פגיע, ירוקה = לא פגיע (כמו על הלוח האמיתי).
- קופסת הכרזות בצבעים הרשמיים: ירוק לפס, אדום לכפל, כחול לכפל חוזר.
- דומם בעמודות לפי סדרה, כמו על השולחן, והשליט ראשון.

## 5. טכנולוגיה
- אתר סטטי בלי שלב בנייה. רץ בכל דפדפן ובאייפון, וניתן להתקנה כאפליקציה (PWA) עם עבודה בלי אינטרנט.
- בדיקת טיפוסים: TypeScript מעל JavaScript (`checkJs`, מצב strict חלקי).
- החשיבה של הבוטים רצה בעובד רקע (Web Worker), כך שהמסך לא נתקע.
