# חומרים להדבקה בצ'אט: שיעור 2

פותחים את הקובץ הזה לפני המפגש ומעתיקים כל בלוק לצ'אט של הזום בשקופית המתאימה.

## שקופית 3: קישור למשחק
```
🧪 נכנסים למעבדה: https://prompt-lab-live.talwa3.chatgpt.site
פתחו בלשונית חדשה, והצטרפו עם כינוי.
```

## שקופית 4: הניסוי (שתי ההנחיות)
```
הנחיה א: כתוב לי מייל ללקוח
הנחיה ב: כתוב מייל ללקוח שמאחר בתשלום 30 יום, טון אדיב אך תקיף, עד 5 שורות, סיום עם הצעת פריסה
```

## שקופית 13: טכניקת הראיון
```
אני רוצה לכתוב [מה]. לפני שאתה כותב, שאל אותי 5 שאלות שיעזרו לך לדייק. שאל שאלה אחת בכל פעם, וחכה לתשובה שלי.
```

## שקופית 18: תחנה 1, שלושה שלדים
```
מי: אתה עוזר שלי. אני [תפקיד] ב[מקום].
מה: מייל דחייה. בחרנו באפשרות אחרת. דלת פתוחה לעתיד. המטרה: לסגור בלי לפתוח משא ומתן.
איך: טון חם ומקצועי, עד 6 שורות, בלי התנצלות, בלי "אשמח לעזור", בלי סימני קריאה.

שלדים נוספים (מחליפים את שורת ה"מה"):
בקשה ברורה: מה: מייל שמבקש [מה] מ[מי], עם תאריך יעד אחד: [תאריך].
תזכורת בלי מלחמה: מה: תזכורת שנייה על [מסמך / משימה / אישור]. בלי האשמה, עם צעד הבא ברור.

אחרי התוצאה: "קצר לשלוש שורות" ואז "מה ישאלו אחרי שיקראו?"
```

## שקופית 19: תחנה 2, ההנחיה לבנק
```
מי: הסיכום הולך למי שלא היה בחדר: [מנהל / צוות / לקוח / שותף].
מה: נקודות גולמיות: [מדביקים]. הפוך למסמך שאפשר לעבוד ממנו מחר בבוקר.
איך: 1) החלטות 2) משימות: משימה | אחראי | תאריך 3) מה פתוח. בלי הקדמה, בלי סיכום בסוף.
אל תמציא החלטה שלא נאמרה.
```

## שקופית 19: נקודות גולמיות להדגמה
```
ישיבת צוות שיווק, יום ב'
- דנה: הקמפיין של החגים מתעכב, הספק של הצילומים לא אישר תאריך
- הוחלט לדחות השקה ל-15 בחודש
- רון בודק ספק צילום חלופי עד יום ה'
- תקציב פרסום: נשאר 12,000 ש"ח, לא סגרנו איך מחלקים בין פייסבוק לגוגל
- מיכל תכין טיוטת מייל ללקוחות קבועים עד יום ד'
- לבדוק אם אפשר לשלב קוד הנחה, אף אחד לא לקח את זה
- הישיבה הבאה: יום ב' הבא, 9:00
```

## שקופית 20: תחנה 3, ארבע שכבות
```
1. סכם את המסמך.
2. אני [תפקיד], לקראת [פגישה / החלטה]. מה חשוב לי לדעת לפני שאני מגיבה?
3. טבלה: נושא | מה כתוב | למה זה חשוב | איפה הזהירות. עד 8 שורות.
4. 3 שאלות לשאול בחדר, ו-3 נקודות שעלולות לעבוד לרעתי.
```

## שקופית 21: Perplexity
```
[שאלה אחת ספציפית]. תשובה קצרה, מקור ותאריך לכל נתון. אם יש מחלוקת, כתוב.

ואחר כך, בכלי הכתיבה:
עדכן את הטיוטה לפי זה, בלי להוסיף עובדות חדשות.
```

## שקופית 23: Gamma
```
בנה מצגת מ-6 שקפים מהסיכום. קהל: [מי מול המסך]. שקף 1 מטרה, 2 עד 4 החלטות, משימות ומה פתוח, 5 הצעד הבא, 6 משפט סגירה. עברית, בלי קישוט.
```

## שקופית 24: הסדנה (נשלח לפני פתיחת החדרים)
```
🛠️ סדנה, 15 דקות בחדר:
1. בחרו משימה מדף העשר שלכם
2. כתבו הנחיה: מי, מה, איך
3. בחרו כלי לפי עץ ההחלטה, והסבירו לשותף למה
4. הריצו פעם אחת
5. שפרו פעם אחת: "קצר יותר" / פורמט אחר / "מה חסר?"
6. ההנחיה שעבדה + שם הכלי נכנסים לבנק
כלל: לא מחליפים כלי באמצע. בסוף: מדביקים במשחק את ההנחיה הכי טובה, לפני ואחרי.
```

## שקופית 27: תרגול בית
```
📌 תרגול בית: לוח שבועי, 3 הנחיות שמורות בבנק
1. משהו שחוזר כל שבוע (הנחיה קבועה)
2. משהו שצריך לנסח לאדם אמיתי (עם "אתה...")
3. משהו עם חומר גלם: מסמך, נקודות או תמלול, בקלוד או ב-NotebookLM, שלוש הודעות באותו צ'אט

הביאו למפגש הבא: התוצר שאתם הכי גאים בו, שלוש ההנחיות עצמן, כישלון אחד שעדיין לא נסגר, ומסמך אחד לא סודי.
```
