# מסלול חשבת

קורס אישי ומדורג מאפס ועד חשבת בחברה גדולה, עם דגש על "החשבת הבונה": מי שמשלבת ידע חשבונאי עם אוטומציה ובינה מלאכותית.

## איך משתמשים

1. פותחים את `index.html` בדפדפן (או את גרסת האתר שפורסמה).
2. עוברים שלב אחרי שלב: קריאה, תהליך, משימה עם קובץ, שכבת AI, מבחן.
3. השלב הבא נפתח רק אחרי ציון 80 ומעלה במבחן. ההתקדמות נשמרת בדפדפן.

## מבנה

| שלב | נושא | קובץ תרגול |
|---|---|---|
| 0 | מפת הדרכים: התפקיד, השכר, המסלול האמיתי | |
| 1 | שפת הכסף: נכס, התחייבות, הון, הכנסה, הוצאה | |
| 2 | חובה וזכות ופקודת יומן | `L02_journal_entries.xlsx` |
| 3 | הדוחות הכספיים | `L03_trial_balance_to_fs.xlsx` |
| 4 | אקסל ו-AI לחשבת | `L04_excel_for_controllers.xlsx` |
| 5 | לקוחות, ספקים ומע"מ | `L05_receivables_aging_vat.xlsx` |
| 6 | התאמות ובקרות | `L06_bank_reconciliation.xlsx` |
| 7 | סגירת חודש | `L07_month_end_close.xlsx` |
| 8 | תקציב, תחזית ותזרים | `L08_budget_vs_actual_cashflow.xlsx` |
| 9 | חשבת בחברה גדולה: IFRS, מבקרים, SOX, איחוד | `L09_consolidation.xlsx` |
| 10 | ארגז הכלים של החשבת הבונה | (בונים על L06, L07, L11) |
| 11 | פרויקט גמר | `L11_capstone_monthly_report.xlsx` |
| 12 | להתמיין ולנצח + מבחן מסכם | |

- `files/` קבצי תרגול. תאים צהובים = כאן ממלאים.
- `files/solutions/` קבצי פתרון. תאים ירוקים = התשובה. פותחים רק אחרי שניסית.
- `tools/build_files.py` יוצר מחדש את כל הקבצים (`pip install openpyxl`, ואז `python3 course/tools/build_files.py`).

## הערות

- כל הנתונים בקבצים בדויים.
- מע"מ 18% (מ-1.1.2025), מס חברות 23%.
- נתוני שכר ודרישות משרה מבוססים על חיפוש משרות וטבלאות שכר פומביות בספטמבר 2026. הם משתנים לפי חברה ותקופה.
- הקורס לא מחליף תעודת רואת חשבון, שנדרשת ברוב משרות החשב/ת בחברות גדולות.
