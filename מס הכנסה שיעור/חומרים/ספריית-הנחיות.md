# ספריית הנחיות: בינה מלאכותית בעבודת הביקורת והשומה

ההנחיות כאן מחולקות לשני חלקים:

- **חלק א׳:** הנחיות שמשרדי רואי חשבון משתמשים בהן היום. מוצגות כדי להכיר את הצד השני של השולחן.
- **חלק ב׳:** הנחיות שאפשר להפעיל בסביבה המאושרת בארגון, על חומר מותר בלבד.

> **לפני כל שימוש:** לעבוד רק בכלי ובסביבה שאושרו, ולפי נהלי אבטחת המידע. לא להעלות מידע מזהה של נישומים לכלי שלא אושר לכך.

---

## חלק א׳: מה המשרדים מריצים היום

### 1. בדיקת כרטסת בעל מניות

```
תפקיד: את/ה בודק/ת כרטסות מנוסה, הבוחן כרטיס חו"ז בעל מניות לקראת דיון.
קלט: ייצוא כרטסת (תאריך, אסמכתא, פרטים, חובה, זכות, יתרה).
בדיקות:
1. יתרת חובה של בעל המניות לאורך השנה ובסופה. ציין/י את החודשים ביתרת חובה.
2. רישומים בתוך 5 ימים לפני סוף השנה, שמתבטלים בסכום זהה בתחילת השנה הבאה.
3. משיכות במזומן, ובפרט סכומים עגולים.
4. הוצאות בעלות אופי פרטי לפי תיאור התנועה.
5. כפילויות: אותו סכום, אותו תאריך ואותו תיאור.
6. שורות ללא אסמכתא.
7. רישומים בשבת או בחג.
פלט: טבלת ממצאים לפי סדר חשיבות, השורות הרלוונטיות, ושאלות מומלצות לדיון.
כללים: אל תקבע/י מסקנה משפטית. סמן/י ושאל/י. כל ממצא מפנה לשורות המקור.
```

### 2. בדיקת שלמות חשבוניות ספקים

```
קלט: תיקיית חשבוניות ספקים לשנה, וכרטסת הספקים מהנהלת החשבונות.
1. קרא/י כל חשבונית וחלץ/י: ספק, מספר עוסק, תאריך, סכום, מע"מ, מספר הקצאה.
2. הצלב/י מול הכרטסת.
3. דווח/י: חשבוניות חסרות לספקים קבועים (לפי חודשים), כפילויות,
   חשבוניות מעל סף החובה ללא מספר הקצאה, ופערים בין המסמך לרישום.
פלט: טבלה לפי ספק, עם סטטוס לכל שורה (תקין, חסר, כפילות, חריג).
```

### 3. ניתוח דוח כספי מנקודת המבט של מפקח

```
תפקיד: את/ה מפקח/ת מס מנוסה הקורא/ת דוחות כספיים של חברה פרטית לקראת דיון.
קלט: דוחות כספיים מבוקרים לשלוש שנים, כולל ביאורים.
1. בנה/י טבלת רווח והפסד ומאזן מקוצרים לשלוש השנים.
2. חשב/י: שיעור רווח גולמי, שיעור רווח תפעולי, ימי לקוחות, ימי מלאי,
   הוצאות רכב מהמחזור, הוצאות מימון מול אשראי. את החישובים יש לבצע בפועל ולא להעריך.
3. זהה/י התגלגלות: לאן הלך הכסף? השווה/י את הגידול במכירות לגידול ברווח,
   במזומן, בלקוחות, במלאי ובאשראי.
4. סמן/י עסקאות עם צדדים קשורים, יתרות בעלי מניות ושינויים חריגים בסעיפי הוצאה.
5. לכל ממצא: כותרת בצורת מסקנה, המספרים התומכים, הפניה לביאור, ו־2 עד 3 שאלות לדיון.
כללים: הפרד/י בין עובדה (מספר בדוח) לבין השערה (הסבר אפשרי). אל תקבע/י חבות.
```

### 4. הכנה לדיון שומה (המשרד מול מפקח מדומה)

```
תפקיד: את/ה מפקח/ת מס מנוסה בדיון שומה. אני המייצג.
חומר רקע: הדוחות והכרטסות המצורפים בלבד.
1. הצג/י בקצרה את התיק, ואז שאל/י שאלה אחת בכל פעם, לפי סדר חשיבות.
2. התעקש/י על מספרים ומסמכים. אם תשובתי כללית, שאל/י שאלת המשך.
3. אחרי כל תשובה שלי, כתוב/י "הערת מאמן": מה חלש בתשובה ואיך מפקח היה ממשיך.
4. כשאכתוב "סיכום": טבלת נושאים, נקודות תורפה, ורשימת המסמכים שמפקח היה דורש.
```

### 5. טיוטת חוות דעת עם מקורות

```
מטרה: טיוטת חוות דעת בנושא [נושא], לקורא [מי הקורא].
מקורות מחייבים מצורפים: [נוסח החוק, הנחיות, פסיקה שנבדקה].
כללים:
1. השתמש/י רק במקורות המצורפים. אם חסר מקור לטענה, כתוב/י "חסר מקור" ואל תשלים/י.
2. ליד כל קביעה, ציין/י סעיף או מסמך מדויק.
3. בסוף, רשימה של כל ההפניות במסמך, לבדיקה ידנית אחת אחת.
```

## חלק ב׳: מה אפשר להפעיל בסביבה המאושרת

### 6. סיכום תיק ארוך לנקודות לדיון

```
קרא/י את המסמכים המצורפים בתיק.
פלט:
1. תקציר של עד 10 שורות: מה העסק, מה השתנה בשנים הנבדקות, ומה הנושאים הפתוחים.
2. טבלת נושאים לדיון: נושא, מה עולה מהמסמכים, הפניה למסמך ולעמוד, ושאלה מוצעת.
3. רשימת מסמכים שלא נמצאו בתיק ונדרשים לבחינת הנושאים.
כללים: אל תסיק/י מסקנה שאינה עולה מהמסמכים. כל קביעה מפנה למסמך.
```

### 7. השוואת דוחות בין שנים

```
מצורפים דוחות כספיים לשנים [X] ו־[Y].
1. טבלת השוואה לכל סעיף: סכום בכל שנה, שינוי בשקלים ושינוי באחוזים.
2. סמן/י שינויים של יותר מ־20% ושל יותר מ־[סכום] ₪.
3. לכל שינוי מסומן: ההסבר שמופיע בביאורים, אם יש, או "לא נמצא הסבר בביאורים".
```

### 8. בדיקת הפניות בחוות דעת שהוגשה

```
מצורפת חוות דעת שהוגשה.
1. חלץ/י כל הפניה: פסק דין (שם, מספר הליך, תאריך), סעיף חוק, תקנה, הנחיה או חוזר.
2. לכל הפניה: הטענה שהיא אמורה לתמוך בה, וציטוט המשפט מחוות הדעת.
3. סמן/י הפניות חסרות פרטים (למשל, פסק דין בלי מספר הליך).
פלט: טבלה לבדיקה ידנית במאגר מוסמך. אל תאשר/י בעצמך שהפניה קיימת.
```

### 9. ניסוח דרישת מסמכים ממוקדת

```
על סמך נקודות הדיון הבאות: [רשימה]
נסח/י דרישת מסמכים מסודרת: מספור, תיאור מדויק של כל מסמך, התקופה הנדרשת,
והנושא שאליו הוא מתייחס. סגנון ענייני וקצר. בלי מסקנות ובלי האשמות.
```

### 10. תרגול דיון שומה (המפקח מול מייצג מדומה)

```
תפקיד: את/ה רואה החשבון המייצג את הנישום בדיון שומה. אני המפקח/ת.
חומר רקע: תיק הדוגמה המצורף בלבד (נתונים בדויים או מותממים).
1. ענה/י כמו מייצג מקצועי שמגן על הלקוח. לפעמים התשובה מלאה, לפעמים כללית,
   ולפעמים סותרת תשובה קודמת. אל תמציא/י מסמכים שאינם בתיק.
2. אחרי כל תשובה, כתוב/י "הערת מאמן": מה חלש בתשובה ואיזו שאלת המשך כדאי לשאול.
3. כשאכתוב "סיכום": טבלת נושאים שנדונו, נקודות תורפה, ודרישת מסמכים מסודרת.
```
