# בינה מלאכותית בצד השני של השולחן

הרצאה בת 90 דקות למאמנים בראיית חשבון ברשות המסים: מה משרדי רואי החשבון עושים היום עם בינה מלאכותית, ומה זה אומר על עבודת הביקורת והשומה.

**מרצה:** טל ולנשטין, רו״ח · קהילת איי איי פיננס

---

## איך מציגים

1. מורידים את **כל התיקייה** למחשב (בגיטהאב: Code ואז Download ZIP, ומחלצים).
2. פותחים את `מצגת.html` בכרום או באדג׳.
3. מקשים:

```
חץ שמאלה / רווח    שקף הבא
חץ ימינה           שקף קודם
N                  הערות מרצה
F                  מסך מלא
```

4. ההדגמות נפתחות מהכפתורים בשקפים 14, 15 ו־18, או ישירות מתיקיית `הדגמות`.

הכול עובד מקומית, בלי חיבור לרשת ובלי התקנה.

## חשוב לדעת

- **כל הנתונים בהדגמות בדויים.** שמות החברות, בעלי המניות, הסכומים והתנועות אינם אמיתיים.
- ההדגמות פועלות עם תשובות וכללים מוכנים מראש, כדי שיעבדו בכל מקום. ההוראות שמאחורי כל כלי מוצגות בתוכו, ואפשר להריץ אותן בכלי בינה מלאכותית מאושר.
- חומר הדרכה בלבד. אינו מהווה ייעוץ או הנחיה מקצועית מחייבת.
